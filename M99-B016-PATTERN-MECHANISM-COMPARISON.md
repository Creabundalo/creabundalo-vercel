## What this means

### RSI
The only pattern feature that separated the directional seed cases from the two WAIT controls was bearish RSI divergence.

This is **not yet predictive evidence** because:
- sample size is 5;
- all three positive cases are crypto from the 2021 cycle;
- asset class and regime are confounded;
- the comparison was not prospectively selected.

Status: **HYPOTHESIS WORTH EXPANDING**.

### Wyckoff
The structural top → reaction/support → retest → break analogue exists in all five selected top/markdown cases, including both WAIT cases.

That means the current structural representation is useful for describing a lifecycle, but **not discriminative by itself**.

Status: **DESCRIPTIVE STRUCTURE, NOT A SIGNAL**.

This also guards against a common misuse: M99 will not translate a Wyckoff-like shape into claims about a hidden operator or intentional manipulation without separate evidence.

### Fibonacci
With a strict ±0.05 ratio tolerance, no directional seed case matched a selected Fibonacci reference, while both WAIT controls had at least one reference match.

This tiny sample cannot prove Fibonacci has no value, but it directly rejects using “near a Fibonacci level” as automatic downside evidence.

Status: **GEOMETRY ONLY; PREDICTIVE VALUE UNPROVEN**.

### Elliott
All five cases produced an Elliott swing candidate because the pivot extraction itself seeks alternating swings.

Therefore candidate presence is not a valid test of Elliott-wave predictive power.

A future Elliott validation would require:
- explicit wave-numbering rules;
- invalidation rules;
- ratio constraints defined before the test;
- negative/random controls;
- out-of-sample scoring.

Status: **CANDIDATE REPRESENTATION ONLY**.
