# M99-B017 — Trickster Validation Across Cases

## Goal
Validate the literal M99 Trickster method across source-complete historical cases:

`meaning / frame ↔ measured mechanism ↔ positioning / flow ↔ regime / outcome`

Trickster is **not** a manipulation detector and **not** a second trading score.

## State model
- `DIVERGENCE_VISIBLE` — positive/constructive meaning coexists with materially stressed downside mechanics.
- `ALIGNMENT_VISIBLE` — meaning and measured stress point in the same broad direction.
- `MEANING_AHEAD_OF_MECHANISM` — strong meaning signal exists while the verified mechanism score remains low.
- `MIXED_OR_LOW_SIGNAL` — no strong classification.

Every state preserves:
- `INTENT_UNKNOWN`
- `actorAttribution = NONE`
- `manipulationStatus = NOT_ESTABLISHED`
- `predictiveStatus = NOT_CALIBRATED`
